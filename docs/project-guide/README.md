Правила поиска XML и диагностика шагов актуализированы 21.10.2026 для API 0.9.6 и сценария СБИС 3.4.0. Для новой логики поиска достаточно JSON 3.2.0 на API 0.8.0+; новые поля журналов требуют API 0.9.3. Текущий JSON 3.4.0 требует API 0.9.4 для сохранения нескольких карточек ведомства во вкладках. Возврат `ip` и `filename` появился в 0.6.17; минимальный совместимый запуск браузера из JSON — в 0.6.19. Номер текущего релиза читайте в [package.json](../../package.json), номер работающей УН — в `/health`. Версия сценария и версия сервиса — разные значения.

Готовые [примеры](examples/): безопасный сценарий с текстовым артефактом, браузерная запись до/после преобразования, входные параметры СБИС. Примеры с placeholder-значениями не являются готовыми отчётами.

Проверка живого API не означает проверку отправки реальной отчётности. Для СБИС подтверждённые и незавершённые этапы перечислены отдельно в документе 07.
