# Инструкции по Script Factory

Начните с [шпаргалки автора сценариев](01-scripts.md): она нужна для самостоятельных экспериментов во время проекта.

| Документ | Для кого и для чего |
| --- | --- |
| [01. Создать сценарий](01-scripts.md) | Аналитик / автор: Recorder → JSON, параметры, условия, циклы, проверка результата |
| [02. Схема проекта](02-developer.md) | Новый программист: очередь, исполнители, база, API и точки изменения |
| [03. Установить на Windows-УН](03-install-windows.md) | Администратор: программы, конфигурация, учётная запись, автозапуск |
| [04. Обновить одну УН вручную](04-update-one-un.md) | Администратор: найти рабочую установку, подготовить ZIP, сохранить состояние, обновить и откатить |
| [05. Параметры СБИС и ui](05-sbis.md) | Разработчик 1С / автор: ведомства, префиксы, ЭЦП, общие и индивидуальные настройки экранов |
| [06. API для 1С](06-api-1c.md) | Интегратор: постановка, результат, IP, файлы, callback, хранение |
| [07. Проверки и подтверждённые ограничения](07-verification.md) | Что проверено кодом, независимо и на УН; что ещё требует реальных отчётов |

Исходная точка пакета — API 0.6.17 с возвратом `ip` и `filename`, сценарий СБИС 2.0.1. Номер текущего релиза читайте в [package.json](../../package.json), номер работающей УН — в `/health`. Версия сценария и версия сервиса — разные значения.

Готовые [примеры](examples/): безопасный сценарий с текстовым артефактом, браузерная запись до/после преобразования, входные параметры СБИС. Примеры с placeholder-значениями не являются готовыми отчётами.

Проверка живого API не означает проверку отправки реальной отчётности. Для СБИС подтверждённые и незавершённые этапы перечислены отдельно в документе 07.
