# Ошибки обновления и журнал оркестратора

В панели откройте «Результаты по УН» → «Диагностика / журналы». Здесь указаны идентификатор операции, конкретная УН и адрес, состояние, причина ожидания, события центра и пути к журналам. «Скачать сведения JSON» сохраняет эти сведения; содержимое Windows-протокола автоматически в центр не передаётся.

## Где искать подробную ошибку

На проблемной УН, по умолчанию в `C:\ProgramData\ScriptFactoryAgent\data`:

- `<ID операции>.result.json.log` — протокол PowerShell установки;
- `<ID операции>.result.json` — результат установщика;
- `<ID операции>.rollback.json.log` и `.rollback.json` — протокол и результат отдельного отката, если он запускался;
- `agent-err.log` — ошибки процесса агента.

Это ID операции обновления из панели, а не job_id задания 1С. Файлы появляются только для выполнявшихся этапов. При другом `data_dir` точный каталог указан в установленном `agent.config.json`.

Пример чтения последних строк (замените имя файла на ID своей операции):

```powershell
Get-ChildItem C:\ProgramData\ScriptFactoryAgent\data -Filter *.result.json.log |
  Sort-Object LastWriteTime -Descending | Select-Object Name,LastWriteTime
# Скопируйте нужный полный путь из списка/карточки диагностики:
$LogPath = Read-Host 'Полный путь к протоколу операции'
Get-Content -LiteralPath $LogPath -Tail 80
```

Перед передачей журнала проверьте его на наличие учётных данных и персональных данных.

## Восстановление, повтор и продолжение

1. При `recovery_required` сначала проверьте локальный протокол, версию API, готовность worker, отсутствие работающего установщика и режим обслуживания. Кнопка подтверждения сама не ремонтирует УН и не устанавливает релиз.
2. Подтверждение доступно после свежего контакта агента, нового heartbeat после ошибки, готовности API и завершения обслуживания. Панель показывает отсутствующее условие.
3. Для открытой раскатки создайте «Повторить» по проблемным операциям. Это ставит новую попытку в очередь. При паузе затем нажмите «Продолжить». Если другие операции ещё требуют восстановления/повтора, центр сообщит об этом.
4. Если окно истекло, выберите «Изменить окно», сохраните новые даты, затем создайте необходимые повторы и продолжите. Изменять окно во время установки нельзя.
5. Если раскатка отменена или завершена, создайте **новую раскатку**. Повтор в закрытой раскатке блокируется: он не должен оставаться в очереди навсегда.

Обычно агент опрашивает центр раз в 30 секунд. Длительная очередь требует проверки причины в строке операции: пауза, окно, связь, пилотные УН или лимит параллельных установок.

## Какой установщик используется

Массовое обновление также использует `docs/project-guide/tools/update-one-un.ps1`: при установке агента этот файл копируется в его каталог, а `fleet/run-update.ps1` вызывает установленную копию. Резервная копия и откат зависят от того, на каком этапе произошла ошибка; нельзя считать любую ошибку подтверждением успешного отката.

Начиная с 0.17.0 общий установщик и запуск нового API планируют обновление отдельного агента: [инструкция](../operator-guide/16-integrated-agent.md). В прежних версиях обновление API не обновляло автоматически отдельную старую копию агента. Для обновления/восстановления агентов используйте массовый bootstrap из актуального полного проекта по [инструкции 11](11-fleet-updates.md). Версия API в панели сама по себе не подтверждает актуальность агента.

## История и удаление регистрации

История операций автоматически не очищается. В журнале доступны поиск по УН, IP, ID операции/раскатки, релизу и причине, фильтры состояний и дат, размер страницы и переход между страницами. События панели показывают последние 200 записей; база центра хранит ограниченный журнал последних 10 000 событий.

Кнопка «Удалить» удаляет регистрацию УН в центре и делает её прежний ключ недействительным. Windows, API и задача агента на самой УН не удаляются. История сохраняется с прежними адресами. УН можно зарегистрировать заново, но старые операции не привязываются к новой регистрации и не допускают повторного запуска.

Удаление блокируется при обслуживании, очереди, активной установке или неподтверждённом восстановлении, а также если регистрация нужна незавершённой раскатке. Сначала завершите/отмените ожидающие операции и безопасно восстановите УН. История не является способом принудительно снять блокировку установки.
