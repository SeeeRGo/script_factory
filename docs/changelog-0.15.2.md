# 0.15.2 — 18.11.2026

- Добавлена массовая первоначальная установка агентов с Windows-контроллера: deploy-fleet-agents.ps1 объединяет CSV, регистрацию, WinRM, передачу индивидуального JSON/публичного ключа, установку задачи SYSTEM и проверку нового heartbeat/готовности API.
- Пилот выбирается через -OnlyUnId, предварительный план — -PlanOnly; поддержаны WinRM HTTP/HTTPS и отдельный порт. Результаты содержат UN_ID, ID, адрес и причину по каждой УН; ошибка одной не прерывает остальные.
- Фактический UN_ID цели проверяется до передачи ключа. Временный каталог защищён и очищается; существующий агент с той же конфигурацией переиспользуется без прерывания работы.
- Ожидающие обновления блокируют bootstrap по умолчанию; осознанный запуск разрешается -AllowQueuedDeployments. Активные/неопределённые операции не прерываются.
- Добавлена инструкция 15-agent-bootstrap.md. Ansible-установка также принимает HTTP-адрес центра во внутренней сети.

Рабочие УН этой доработкой не изменялись; полноценный пилот с реальным WinRM и установкой задачи выполняется отдельно.

Проверено: 27 проверок в Windows PowerShell 5.1 (включая массовый сценарий с подменёнными адаптерами), синтаксис Ansible YAML и состав подписанного пакета.
