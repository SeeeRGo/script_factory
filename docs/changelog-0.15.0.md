# 0.15.0 — 18.11.2026

- Повторяемая регистрация по полному инвентарю: сохранение канонического ID по UN_ID, проверка и переиспользование действующих ключей, явное восстановление потерянных через --recover-existing, просмотр плана --dry-run, блокировка параллельных запусков и резервная копия изменённых JSON.
- Windows sync-fleet-enrollment.ps1 преобразует CSV и формирует конфигурации одной командой, независимо от рабочего каталога.
- Windows publish-fleet-release.ps1 собирает HEAD и публикует именно полученные manifest/ZIP. Не требуется подстановка КОММИТ_РЕЛИЗА и ID. Низкоуровневый build допускает отсутствие --ref.
- Обновлены инструкции главной УН и выпуска релизов. Автоматический старт раскатки не выполняется.

Проверки: локальные интеграционные тесты регистрации/повторного запуска/восстановления и выпуска подписанного пакета. Новые PowerShell-обёртки требуют пилота в Windows PowerShell 5.1; на УН в этой доработке не устанавливались, ключи заказчика не менялись.
