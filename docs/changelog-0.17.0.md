# 0.17.0 — 19.11.2026

- Общий установщик API принимает индивидуальный FleetConfigFile и ReleasePublicKey и планирует первую установку агента. deploy-one-un и пакетная установка поддерживают тот же путь.
- Проверенное обновление и запуск нового API под SYSTEM планируют синхронизацию установленного агента из нового релиза, включая переход со старого updater. Существующие ключ, идентификаторы и настройки сохраняются.
- Независимая задача Windows ждёт завершения операции, передачи накопленных результатов и готовности API, повторно проверяет журнал после остановки и заменяет только агент. Резервная копия кода/конфигурации/задачи восстанавливается при ошибке установки или отсутствии нового контакта с центром.
- Версия исходников агента и состояние его обновления передаются в центр и отображаются отдельно от версии API. Добавлены agent-sync.log, agent-sync-result.json и подтверждение контакта agent-contact.json.
- Обновлены инструкции первой/массовой установки, обновления и диагностики. Старый сбой до запуска нового API требует однократного bootstrap/восстановления агента.

Проверки: 47 интеграционных тестов fleet и 23 проверки транзакции PowerShell на временных файлах с подменой Windows-задач, HTTP, ACL и установщика. Реальное выполнение планировщика и job object на рабочих УН этим релизом ещё не проверялось.
