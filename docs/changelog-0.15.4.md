# 0.15.4 — 18.11.2026

- Массовый bootstrap автоматически обновляет отдельный код агента при отличии файлов источника, сохраняя код, конфигурацию, XML задачи и существующий каталог данных. Активные операции и установщики не прерываются. При ошибке восстанавливаются прежний код и задача.
- С -RecoverExisting WinRM, права, Node, UN_ID, SYSTEM/SID, публичный ключ и отсутствие активного обновления проверяются на всех выбранных целях до перевыпуска ключей центра.
- Новый токен/адрес центра/канонический ID автоматически переносятся в установленный агент при явном восстановлении. При откате кода сохраняется новый действующий токен, а не отозванный старый.
- agent-source.json фиксирует версию исходников агента, понижение блокируется. Требуется полный исходный комплект 0.15.4+, включая package.json; Ansible также передаёт этот файл.
- Обновлены инструкции массовой установки, восстановления и обновления отдельного агента.

Проверки: 40 условий/сценариев Windows PowerShell 5.1, включая выполнение реального блока согласования агента на временных файлах с подменой планировщика/WinRM/HTTP. На Михееве вручную доставлен исправленный updater 0.15.3 и затем успешно выполнено штатное обновление API через оркестратор до 0.15.3. Новый массовый bootstrap 0.15.4 на рабочих УН пока не запускался.
