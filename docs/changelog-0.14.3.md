# API 0.14.3 — защита каталогов CLI без изменения владельца и аудита

Общий helper privateDirectory на Windows изменяет только DACL через DirectoryInfo.GetAccessControl(Access) и SetAccessControl. Больше не создаётся новый полный security descriptor, не меняется владелец и не вызывается Set-Acl. Наследование отключается; полный доступ остаётся у текущего пользователя, SYSTEM и Administrators. Требуются обычные права изменения разрешений каталога, а не привилегия аудита SeSecurityPrivilege.

При отказе возвращается DIRECTORY_PERMISSION_ERROR с путём и пояснением. Вывод powershell.exe -EncodedCommand/CLIXML больше не попадает целиком в ошибку Node. Если ограничить права не удалось, операция останавливается до записи новых секретных файлов.

Веб-форма релиза отличает nodes.json от подписанного manifest и объясняет ошибку до загрузки. В панели добавлена подсказка: регистрация УН, конфигурация агента и загрузка подписанного релиза — разные действия.

Инструкции дополнены разбором Windows ACL и порядком действий через веб-панель.
