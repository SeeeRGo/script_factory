# 0.16.0 — 19.11.2026

- Карточка диагностики операции: причина ожидания, состояние УН, события центра, пути к локальным протоколам и скачивание сведений JSON. Сами Windows-протоколы остаются на УН.
- Поиск, фильтры состояний и дат, страницы журнала раскаток, операций и событий. Ошибки действий видны в закреплённом сообщении.
- Удаление регистрации УН с подтверждением, отзывом доступа и сохранением истории. Обслуживание и незавершённые операции блокируют удаление; новая регистрация не получает права на старые операции.
- Изменение окна при остановленной установке. Повтор в закрытой/просроченной раскатке блокируется с пояснением, продолжение сообщает о незавершённых восстановлениях.
- Добавлена инструкция по журналам, восстановлению и отличию обновления API от отдельного агента.

Проверки: 46 тестов fleet, включая HTTP-права, сохранность истории, повторную регистрацию, очередь и партии 300 УН. Поиск и карточка диагностики проверены в Chromium на локальных тестовых данных. Изменения панели на рабочих УН в рамках этого релиза не устанавливались.
