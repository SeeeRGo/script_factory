# 0.15.1 — 18.11.2026

- Выпуск релиза без --ref получает свежий origin/main и собирает точный полученный коммит. Старый локальный HEAD и незакоммиченные изменения больше не определяют пакет по умолчанию.
- Fetch использует отдельную временную ссылку для каждого запуска, не переключает checkout, не меняет рабочие файлы и не использует локальный кеш при ошибке сети/авторизации. Git-запрос ограничен по времени, интерактивный запрос авторизации отключён.
- Доступны --remote/--branch, осознанный локальный выпуск через --ref. Windows-обёртка поддерживает -Remote/-Branch/-Ref и показывает версию/хеш перед публикацией.
- Понятные ошибки выпуска выводятся в stdout с ненулевым кодом для Windows PowerShell ISE.
- Инструкции заменяют порядок выпуска из локального HEAD на обновляемый источник Git.

Проверено интеграционными тестами: свежий удалённый коммит при старом HEAD и грязной рабочей папке, неизменность файлов/HEAD, явная фиксация старой ревизии, отсутствие ветки/remote и недоступный репозиторий, очистка временных ссылок, подпись и исключение секретов из ZIP. Проверка новой PowerShell-обёртки на реальной УН пока не выполнялась.
