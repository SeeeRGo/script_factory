# Инструкции администратора и автора сценариев

Установщик не устанавливает ЭЦП, криптопровайдер, Saby, Node.js, браузер и не настраивает автоматический вход Windows. Эти компоненты готовит администратор. API работает под SYSTEM, браузерный worker и Saby — под локальным robot либо явно выбранным пользователем.

Старый `ansible/deploy-windows.yml` описывает другую структуру releases/shared и прежний запуск. Не используйте его как готовую массовую установку режима broker 0.11.0. Новый комплект использует штатный Windows-установщик, помощник обновления и оркестратор. `ansible/install-fleet-agent.yml` предназначен только для установки агентов поверх уже подготовленного API.

Видео пока не записано. Инструкция 06 содержит воспроизводимый пример, который можно запустить без 1С и без СБИС.
