# Подготовка env с общими значениями заказчика

Для новой установки предусмотрен `windows/prepare-rollout-env.ps1`. Он берёт базовый Windows-шаблон, накладывает общий защищённый env и создаёт индивидуальный итоговый файл. Рабочие конфигурации не перезаписывает. У API не появляется новый механизм загрузки: он по-прежнему читает один готовый env.

## Общие значения

В согласованном профиле: PORT=33001, MAX_PARALLEL_JOBS=1, DEFAULT_JOB_TIMEOUT_MS=300000, JOB_RETENTION_DAYS=7, CALLBACK_ALLOWED_ORIGINS=https://dev.companya.ru. API_KEY и реквизиты Basic callback берутся из защищённого общего файла; в Git их нет. Один общий API_KEY технически поддерживается; смена такого ключа потребует согласованной настройки всех использующих его клиентов.

Callback использует только HTTP Basic через CALLBACK_AUTH_USERNAME/CALLBACK_AUTH_PASSWORD. Поддержка Bearer в обратном вызове удалена из новой версии; общий шаблон не содержит токена.

`FILESYSTEM_ALLOWED_ROOTS=C:/` разрешает сценариям доступ ко всем каталогам диска C в пределах Windows-прав worker. Это не выдаёт права Windows на защищённые папки. Для сети нужен полный путь к общей папке, например `C:/;\\fileserver\Reports`, а не `\\fileserver` без имени share. Каждая отдельная общая папка требует своего корня. Пользователь robot должен иметь сетевые права; локальные права администратора установщика их не заменяют.

В исходном перечне питания указаны одновременно 3600 секунд и пояснение «30 минут». 30 минут = 1800, 60 минут = 3600; требуется согласовать значение. Пока значение и сетевой путь не уточнены, общий файл помечен ROLLOUT_PENDING и помощник откажется применять его. Удалять эту пометку следует только после заполнения согласованных значений.

## Что заполняется индивидуально

UN_ID не может быть пустым при запуске API. Помощник устанавливает его из параметра -UnId инвентаря либо как `un-` + имя Windows-компьютера в нижнем регистре. UN_ID из общего файла намеренно не копируется. Уникальность имён компьютеров проверяет администратор; при повторяющихся именах явно передайте разные -UnId. На существующей установке UN_ID сохраняют, заново помощник не запускают.

WEB_PASSWORD сохраняется из общего файла, если задан реальный пароль. Если там только заглушка или пустое значение, генерируется индивидуальный случайный пароль и сохраняется в итоговом env без вывода. WORKER_ACCOUNT, WORKER_AUTH_TOKEN и WORKER_PORT сбрасываются перед первой установкой: штатный install-task.ps1 привяжет правильного пользователя и создаст индивидуальный секрет канала.

## Подготовить новую УН

Передайте общий файл через защищённый административный канал в каталог, доступный только SYSTEM/Administrators. В повышенной Windows PowerShell 5.1:

```powershell
& C:\script_factory\windows\prepare-rollout-env.ps1 `
  -ProjectPath C:\script_factory `
  -CommonEnvFile C:\ProgramData\ScriptFactoryDeploy\common.env `
  -UnId 'un-001'

& C:\script_factory\windows\install-task.ps1 -ProjectPath C:\script_factory -Port 33001
& C:\script_factory\windows\install-saby-task.ps1 -ProjectPath C:\script_factory
```

Без -UnId будет использовано имя текущего Windows-компьютера. Итоговый файл создаётся как C:\script_factory\.env; его чтение первоначально ограничено SYSTEM и Administrators. Установщик затем выдаёт чтение worker. После успешной установки удалите временную копию common.env с УН; исходник храните в защищённом хранилище развёртывания.

Для десяти УН вызовите помощник непосредственно на каждой целевой машине в цикле из [инструкции установки](02-install-ten.md), подставляя UnId из инвентаря. Вместо копирования десяти готовых env передаётся общий файл. Для уже работающих УН используйте [выборочную замену настроек](05-env-management.md): помощник первой установки откажется перезаписать существующий env.

Это подготовка только конфигурации. Она не включает фоновое выключение, не меняет существующие API-переопределения питания/очереди, не устанавливает сертификаты и не проверяет сетевые права robot. Перед массовым применением проверить помощник и запуск на одной Windows Server 2022; локальная подготовка файла не является Windows-приёмкой.
