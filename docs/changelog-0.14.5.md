# API 0.14.5 — понятная диагностика регистрации агентов

fleet:enroll предварительно проверяет весь JSON-инвентарь, доступ к центру, существующие id/UN_ID (включая отозванные записи) и локальные файлы конфигурации. При конфликте новая регистрация не начинается. Отзыв не трактуется как удаление; существующие токены и конфигурации автоматически не меняются.

HTTP-статус, код и сообщение центра показываются в коротком сообщении stdout, после чего CLI завершается с ненулевым кодом. Это устраняет потерю причины ошибки в PowerShell ISE при ErrorActionPreference=Stop. FLEET_ADMIN_TOKEN маскируется в диагностике. Для отсутствующего JSON выводится подсказка о конвертере CSV; частичные успехи при серверном сбое сохраняются.

[Инструкция по существующим и отозванным регистрациям](operator-guide/14-existing-csv.md).
