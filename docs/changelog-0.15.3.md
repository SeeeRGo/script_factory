# 0.15.3 — 18.11.2026

- Исправлено чтение /health с HTTP 503 в Windows PowerShell 5.1: тело ответа сначала читается из ErrorDetails, затем из потока. Обслуживание своего обновления больше не приводит к ложному отказу «Current worker is not ready» до установки. Исправление применяется к обновлению кода, откату и изменению конфигураций.
- Повторная установка агента распознаёт локализованное имя SYSTEM по SID S-1-5-18 (включая «СИСТЕМА»).
- Регрессионный тест на реальном HTTP-сервере с ответом 503 проверяет все три обработчика, собственное/чужое обслуживание и запрет при отсутствии владельца.

На Нефедове подтверждён сбой до замены кода, выполнена штатная smoke-проверка и снята собственная блокировка обслуживания. У Михеева подтверждено несовпадение ключа, установлен актуальный ключ существующей регистрации без нового перевыпуска, перезапущена только задача агента.

Проверки: 15 проверок Windows PowerShell 5.1 и 39 интеграционных тестов оркестратора. Три исправленных утилиты обновления установлены в отдельную копию агента Нефедова с резервными копиями, без перезапуска API. На Михееве изменён только токен и перезапущен агент; исправление его updater-кода пока не устанавливалось.
