# API 0.14.1 — HTTP оркестратора во внутренней сети

CLI регистрации агентов, публикации релизов, экспорта конфигурации и агенты принимают HTTP и HTTPS origin центрального сервера. Убрано прежнее ограничение «HTTP только на loopback» для центра. Дополнительного флага нет: транспорт выбирается адресом --url/central_url. Локальный api_url агента по-прежнему должен указывать на loopback API этой же УН.

Сервер центра уже обслуживает HTTP: для сетевого подключения укажите FLEET_HOST=0.0.0.0 либо адрес интерфейса, нужный FLEET_PORT и настройте доступ к порту. Reverse proxy требуется только при выбранной схеме HTTPS. Авторизация и проверка подписи пакетов не отключены.

Обновить нужно CLI на компьютере выпуска и отдельную установленную копию агента на уже подключённых УН. Индивидуальные токены и идентификаторы сохраняются. [Настройка и диагностика](project-guide/11-fleet-updates.md).
