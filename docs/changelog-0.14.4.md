# API 0.14.4 — существующий CSV для регистрации агентов

Добавлен windows/convert-fleet-inventory.ps1: CSV с Computer,EnvFile из первоначального внедрения преобразуется в nodes.json для fleet:enroll. Из подготовленных env читаются только UN_ID и PORT; секреты не экспортируются. Id по умолчанию равен UN_ID, если он подходит для идентификатора агента; доступна явная колонка Id. Удалённый путь env агента формируется из ProjectPath, а не из локального EnvFile на компьютере выпуска.

Все строки проверяются до записи. Поддержаны CSV с запятой/точкой с запятой, относительные EnvFile, необязательные Id/Group/ProjectPath/RdpAddress. Один узел тоже записывается JSON-массивом. Повторная конвертация одинаковых данных не меняет файл; другой существующий JSON заменяется только с -Force. Исходные CSV и env не перезаписываются.

Инструкция оркестратора проверяет наличие inventory до запуска CLI. Добавлен [порядок работы с главной УН и существующим CSV](operator-guide/14-existing-csv.md): подготовка JSON, проверка соответствия УН, регистрация, отличие регистрации от установки агентов и обновления API. Конвертация не подключается к рабочим столам и не меняет автологин Windows.
