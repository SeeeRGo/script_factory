# Проверка выбора XML в СБИС на УН

- `sbis-upload-stub.json` — сценарий Puppeteer Replay для редактора системы.
- `sbis-upload-stub.request.json` — готовое тело `POST /api/v2/jobs`.
- `fixtures/TEST_ONLY_NOT_A_REPORT.xml` — явная тестовая заглушка, не отчёт.

Перед запуском скопируйте заглушку в `Downloads` пользователя, под которым работает worker. На тестовой УН это `C:\Users\robot\Downloads\TEST_ONLY_NOT_A_REPORT.xml`. В его интерактивном сеансе должны работать Yandex Browser и приложение Saby, быть доступны CryptoPro и сертификат для входа. Сценарий проверен для текущего кабинета с автоматическим выбором единственного сертификата; выбор из нескольких сертификатов и запрос PIN не реализованы.

Отправьте содержимое `sbis-upload-stub.request.json` на `http://127.0.0.1:33001/api/v2/jobs` непосредственно с тестовой УН, с заголовками `Content-Type: application/json` и `X-API-Key` из конфигурации worker. В JSON нет `uid`: каждый POST создаёт новое задание. Для интеграции с 1С задавайте собственный уникальный `uid` операции. Статус доступен через `GET /api/v2/jobs/{job_id}`.

Сценарий входит по ЭЦП, открывает `report.saby.ru`, выбирает «Загрузить → С компьютера → Загрузки» и открывает заглушку двойным щелчком. Последние два шага проверяют видимость вопроса «Что сделать с файлом?» и имени файла. Отсутствие ожидаемого результата завершит задание ошибкой, а не ложным успехом. Содержимое кабинета целиком в журнал не записывается.

Этот сценарий использует файловый диалог Saby. Расширение `customStep/uploadFiles` ему не требуется. JSON самостоятельно не копирует файл и не запускает приложение Saby: это условия подготовки УН.

Ожидаемый результат — просмотр XML и предложение «Переместить» / «Создать». Кнопки создания, подписания и отправки не нажимаются. `success` подтверждает только этот сценарий, а не проверку или принятие отчётности ведомством. Для настоящего отчётного XML нужен отдельный сценарий проверки результата импорта.

При сетевой ошибке до открытия файла можно повторить запуск; автоматические повторы в запросе отключены. Проверка наличия Saby и управление его запуском относятся к подготовке УН, а не к этому браузерному JSON.
