Адреса и название УН

UN_ID не меняется. В результатах операции сохраняются адреса на момент её создания. Фактическое имя Windows и локальные IP дополнительно сообщает агент.

Конфигурации и секреты

Общий профиль → переопределения УН → отдельное применение. Секреты шифруются на сервере и повторно не показываются. Пароль Windows используется только для защищённой выгрузки первичной установки.
